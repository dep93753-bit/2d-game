# Port Tycoon (working title)

A side-view, pixel-art idle tycoon game about running cargo ports, built with plain HTML, CSS and JavaScript.

- Play: open `index.html` through any static web server, or use GitHub Pages.
- Project docs: [`docs/VISION.md`](docs/VISION.md), [`docs/TECH.md`](docs/TECH.md), [`docs/PLAN.md`](docs/PLAN.md)
- Credits: [`CREDITS.md`](CREDITS.md)

## Run locally
```
python3 -m http.server 8000
# then open http://localhost:8000
```
(Opening the file directly with `file://` won't work, because browsers block JavaScript modules there.)
